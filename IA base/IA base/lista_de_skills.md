# Lista de Habilidades de IA (Skills) - Antigravity

Esta es la lista completa de habilidades de inteligencia artificial disponibles en mi sistema, preparadas para interactuar y automatizar diferentes tareas y proyectos:

## 🤖 Inteligencia Artificial e Integraciones
* **agency-ai-engineer**: Especialista en machine learning y la integración de LLMs.
* **agency-mcp-builder**: Desarrollo de servidores bajo el estándar Model Context Protocol (MCP).
* **agency-prompt-engineer**: Optimización sistemática de prompts para modelos de lenguaje.
* **agency-agents-orchestrator**: Orquestación y gestión de flujos de trabajo multi-agente complejos.
* **agency-agentic-identity-trust-architect**: Arquitectura de confianza e identidad para agentes autónomos.
* **agency-ai-citation-strategist**: Estrategias de visibilidad y optimización para motores de recomendación de IA (GEO/AEO).
* **agency-aeo-foundations-architect**: Infraestructura para la indexación y optimización de cara a rastreadores de IA.
* **agency-voice-ai-integration-engineer**: Integración de canales de voz interactivos y telefonía con IA.
* **agency-ai-data-remediation-engineer**: Remediación y preparación de datos específicos para entrenamiento e inferencia de IA.

## 💻 Desarrollo de Software y Arquitectura
* **agency-backend-architect**: Diseño de sistemas robustos, microservicios y lógica del lado del servidor.
* **agency-software-architect**: Diseño de software utilizando patrones avanzados y Domain-Driven Design (DDD).
* **agency-database-optimizer**: Optimización de bases de datos relacionales (PostgreSQL, MySQL) y no relacionales.
* **agency-api-tester**: Pruebas funcionales, de rendimiento y seguridad para APIs.
* **agency-mobile-app-builder**: Desarrollo de aplicaciones nativas e híbridas para iOS y Android.
* **agency-frontend-developer**: Desarrollo de interfaces web de alto rendimiento y uso de frameworks modernos.
* **agency-ui-designer**: Creación de sistemas de diseño visual y componentes UI accesibles y estéticos.
* **agency-ux-architect**: Diseño de flujos de navegación, experiencia de usuario y fundamentos CSS robustos.
* **agency-ux-researcher**: Investigación cualitativa y cuantitativa de la experiencia de usuario.
* **agency-wordpress-shopping-cart-engineer**: Creación y optimización de tiendas virtuales mediante WooCommerce.
* **agency-drupal-shopping-cart-engineer**: Desarrollo de comercio electrónico avanzado sobre Drupal Commerce.
* **agency-cms-developer**: Desarrollo personalizado en gestores de contenido como WordPress y Drupal.
* **agency-cross-border-e-commerce-specialist**: Logística y comercio electrónico internacional.
* **agency-application-security-engineer**: Seguridad en el ciclo de vida del software (AppSec, SAST/DAST).
* **agency-penetration-tester**: Pruebas de penetración y auditorías de seguridad ofensivas.
* **agency-cloud-security-architect**: Arquitectura de seguridad en la nube (AWS, Azure, GCP).
* **agency-devops-automator**: Automatización de infraestructura y pipelines CI/CD.
* **agency-sre-site-reliability-engineer**: Confiabilidad del sistema, gestión de SLOs y presupuestos de error.
* **agency-infrastructure-maintainer**: Mantenimiento de operaciones técnicas de servidores.
* **agency-code-reviewer**: Revisión de código en base a buenas prácticas y mantenibilidad.
* **agency-git-workflow-master**: Flujos de trabajo y estrategias de ramas en Git.
* **agency-security-architect**: Diseño integral de la arquitectura de seguridad a nivel corporativo.
